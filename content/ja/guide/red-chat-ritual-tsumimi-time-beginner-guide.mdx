## チャットマナーとタイミングのルール

Red Chat Ritual TSUMIMI TIMEのマナーは、形式的であることではありません。グループのタイミングを守ることです。余分なメッセージはすべて、誰かが読み飛ばさなければならないノイズになります。

| すべきこと | してはいけないこと |
|---|---|
| 投稿前にピン留めメッセージを読む | ピン留めの説明にすでに書かれていることを質問する |
| 返信は短く、形式通りに保つ | 合図が進行中のときに長い複数行のメッセージを送る |
| 質問は切れ目を待ってする | シーケンスを脱線した雑談で中断する |
| モデレーターの指示にはすぐ従う | セッションの最中にルールについて議論する |
| 指定されたチャンネルだけを使う | 同じメッセージを複数のチャットにクロスポストする |

コミュニティの報告では、最大の混乱要因として一貫してある行動が挙げられています。それは、シーケンス進行中に「親切心から」質問に答えてしまう参加者です。正しい答えであってもリズムは崩れます。助けたいなら、終了の時間帯まで待ちましょう。

タイミングの規律は、終わりを尊重することも意味します。主催者がTSUMIMI TIMEの終了を合図したら、儀式は終わりです。終了後の居残りメッセージは、次のグループとの境界を曖昧にし、セッション後の振り返りを難しくします。

## よくある初心者のミスとその直し方

初回の問題のほとんどは予測可能です。ここでは繰り返し起こるものを、すぐに実践できる修正方法とともに紹介します。

| ミス | どんな風に見えるか | 修正方法 |
|---|---|---|
| 遅れて参加して推測する | 2ステップ前の合図を入力してしまう | 1サイクル見てから、現在のステップに戻る |
| 過剰参加 | 合図ごとに2～3回返信する | 合図ごとに1回返信し、待つ |
| 間違ったチャンネル | 習慣で一般チャットに投稿する | redチャンネルをピン留めするか、アクティブタブに固定する |
| 形式のずれ | 余計な句読点、絵文字、大文字 | 直近の正しいメッセージのスタイルを正確にコピーする |
| 終了を無視 | 終了合図の後も続ける | 合図で止める。例外なし |
| メモなし | シーケンスの中盤を忘れる | スクラッチノートにリストを随時更新する |
| 黙った混乱 | 何も聞かずに去る | 終了の時間帯に1つ明確な質問をする |

これらほぼすべての背景にあるパターンは同じです。読むより先に行動してしまうこと。一拍だけ遅らせれば、ほとんどが解決します。

## 毎回のセッションをより充実させるコツ

- **リハーサルをする。** セッション開始前に説明を一度声に出して読む。暗記より慣れが勝つ。
- **参加する前にセッションを見る。** 1サイクル全体を観察するのが、形式を学ぶ最速の方法。
- **自分用の合図シートを作る。** 2～3回参加したら、順序の短い自分版を書く。
- **アラームを2つ設定する。** 10分前と開始時刻に。
- **自分の一貫性を記録する。** どの合図を逃し、なぜかをメモする。パターンはすぐ見えてくる。
- **1セッションにつき1つ質問する。** 学び続けられ、チャットを溢れさせない。
- **自分の好奇心よりグループのペースを優先する。** 好奇心は終了後には歓迎されるが、進行中はそうではない。
- **主催者の説明を保存する。** ルールは変わる。保存したコピーが何が変わったかを教えてくれる。

最初の数回を終えた後にもっと深く学びたいなら、自然な次のステップは各合図の「何を」だけでなく「なぜ」を学ぶことです。ステップの目的を理解しているプレイヤーは、グループがバリエーションを実行するときによりうまく適応します。これは固定スクリプトではなくコミュニティの儀式なので、バリエーションはよくあります。

| 経験レベル | セッションの焦点 | 現実的な目標 |
|---|---|---|
| 初回 | 観察して形式を合わせる | リズムを崩さずに1サイクルを完了する |
| 2～3回目 | タイミングとペース | 重複返信ゼロ |
| 4回目以降 | 各合図の目的を理解する | バリエーションを実行するグループに適応する |
| 常連参加者 | 新規参加者を助ける | 終了の時間帯にだけ質問に答える |

## FAQ

**Red Chat Ritual TSUMIMI TIMEを試す前に、経験豊富なTSUMIMIプレイヤーである必要がありますか？**

**セッションはどのくらい続きますか？**
長さは主催者とグループの規模によって変わります。コミュニティの報告では、セッションは開かれた雑談ではなく短く構造化されたブロックで進行するとされています。そのため、途中で出入りするのではなく、時間枠全体に参加するつもりでいてください。

**Red Chat Ritual TSUMIMI TIMEで合図を逃したらどうすればいいですか？**
逃したステップを投稿して追いつこうとしないでください。次の合図を見て、現在の形式に合わせ、そのギャップを次回のためにメモしましょう。追いつこうとすることが、チャットの散らかりの最大の原因です。

**このRed Chat Ritual TSUMIMI TIME初心者ガイドはすべてのグループに当てはまりますか？**
これはルールブックではなく枠組みです。各コミュニティは独自の文言、タイミング、チャンネル名を設定しているので、ここに書かれた内容と矛盾する場合は常に主催者の説明を優先してください。

小さく始め、早めに到着し、入力する前に見て、リズムを自分に来させる。それが初心者戦略のすべてを一文にしたものです。
